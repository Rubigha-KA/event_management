# Event Management System

A menu-driven **Event Management System built using C++ and Object-Oriented Programming (OOP)** to manage event details and participant registrations with text-file data persistence.

## Overview

Managing events manually can make it difficult to maintain participant records, search for events, and update information consistently. This project provides a console-based solution for organizing events and managing registrations efficiently.

The system allows users to create, display, search, update, and delete events. It also supports participant registration, participant lookup and removal, event-wise participant listing, and persistent storage of records using text files.

This mini project demonstrates the practical application of **encapsulation, abstraction, inheritance, and polymorphism** in C++.

## Features

### Event Management
- Add new events.
- Display event records.
- Search for events using their IDs.
- Update event details.
- Delete events.
- Count registered events.

### Participant Management
- Register participants for existing events.
- Display participant records.
- Search for participants using their IDs.
- Remove participants.
- Count registered participants.
- List participants associated with a particular event.

### Data Validation and Persistence
- Validate user input.
- Prevent duplicate participant IDs.
- Prevent duplicate participant email addresses.
- Verify that an event exists before registering a participant.
- Save event and participant records to text files.
- Load saved records when the application starts.

## System Architecture

The project separates responsibilities across domain classes, manager classes, and file-handling classes.

- **Event:** Represents common event information and behavior.
- **Workshop:** Represents a workshop-specific event type.
- **CulturalEvent:** Represents a cultural event type.
- **EventManager:** Handles event creation, display, search, updates, deletion, and counting.
- **Participant:** Represents participant information.
- **ParticipantManager:** Handles participant registration, display, search, removal, counting, and event-wise listing.
- **FileManager:** Handles saving and loading event records.
- **ParticipantFileManager:** Handles saving and loading participant records.
- **main.cpp:** Provides the program entry point and menu-driven interaction.

## Installation and Setup

### Prerequisites

Install a C++17-compatible compiler such as GCC/G++ and ensure that it is accessible from your terminal.

Verify the installation using:

```bash
g++ --version
```

### Compilation

Open a terminal in the project directory and run:

```bash
g++ -std=c++17 -Wall -Wextra main.cpp Event.cpp Workshop.cpp CulturalEvent.cpp EventManager.cpp FileManager.cpp
```

**Important:** If the participant-related source files contain separate implementations that are not included through the files above, add `Participant.cpp`, `ParticipantManager.cpp`, and `ParticipantFileManager.cpp` to the compilation command as required by your actual source code.

### Execution

On Windows PowerShell:

```powershell
.\EventManagementSystem.exe
```

On Linux or macOS, run the executable generated by your compiler. For example, if you compile with `-o EventManagementSystem`:

```bash
./EventManagementSystem
```

7. Exit and restart the application to verify that saved records persist.
